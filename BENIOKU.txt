afi sınıf - AFİ KOD sınıf sürümü
================================
İndirme ve kurulum: https://aydinincekara.github.io/isikcirobot_offline/

TEK KURULUM DOSYASI: afi-sinif-kurulum.exe
Hem öğretmen hem öğrenci bilgisayarında aynı dosya çalıştırılır; kurulum türü sihirbazda seçilir.
"Bilgisayarınız korundu" çıkarsa: Ek bilgi > Yine de çalıştır.

ÖĞRETMEN BİLGİSAYARI
1. Kurulum dosyasını açın, "Tüm kullanıcılar için" seçin (yönetici izni; güvenlik duvarı izni kurulumda verilir).
2. Lisansı kabul edin, kurulum türünde "Öğretmen bilgisayarı (sunucu)" seçin.
3. Klasörü (C:\afikod), sunucu adını, portu (8000) ve kayıt klasörünü kontrol edip kurun. Bitince
   öğretmen paneli açılır; ilk açılışta admin hesabını oluşturun.
4. Sunucu penceresiz çalışır: saatin yanındaki afi simgesi (görünmüyorsa ^ okunun içinde) panelini açar,
   sağ tıkla "Sunucuyu kapat". Panelde "AFİ KOD'u aç" uygulamayı öğretmen olarak açar.
   Sunucu bilgileri: panel > Ayarlar. Kayıtlar: C:\afikod\kayitlar\sunucu

ÖĞRENCİ BİLGİSAYARI
1. Aynı kurulum dosyasını açın, "Öğrenci bilgisayarı (istemci)" seçin. Sunucu adresi boş kalabilir.
2. Masaüstüne "AFİ KOD" simgesi gelir; program Windows açılışında arka planda başlar.
   Ağ yokken de çalışır; sunucuyu kendisi bulur. Bulamazsa üstteki "Sınıf bağlantısı yok" etiketine
   tıklayıp adresi yazın (ör. 192.168.1.20:8000).
- Kurulumsuz: tarayıcıda http://ÖĞRETMEN-PC:8000 açılır.

TOPLU (SESSİZ) KURULUM
Yönetici Komut İstemi'nde, kurulum dosyasının klasöründe tek satır:
  afi-sinif-kurulum.exe /VERYSILENT /ALLUSERS /ROL=istemci
  (öğretmen için: /ROL=sunucu /PORT=8000)

AYAR DEĞİŞTİRME / KALDIRMA
Kurulum dosyasını yeniden açın: "Güncelle ya da ayarları değiştir" ya da "Kaldır".
Denetim Masası > Programlar'dan da kaldırılabilir. Öğrenci kayıtları sorulmadan silinmez.

NOT: Windows Mobil etkin nokta en fazla 8 cihaz bağlar; kalabalık sınıfta okul ağı ya da ayrı modem kullanın.

PYTHON İLE (exe yerine, isteğe bağlı)
Python 3.8+ gerekir. Bu klasörde Komut İstemi açıp komutları teker teker yazın:
  python --version          (sürüm görünmezse:  py --version  ve aşağıda python yerine py)
  python afi-sunucu.py      (öğretmen bilgisayarında)
  python afi-istemci.py     (öğrenci bilgisayarında)
Yönetici izni gerekmez.
